## How it works

Let's say you want to take a copyrighted picture, but can't distribute it legally. Bitripper solves this in many smart ways:
<br><br>
First, you take a file. This can be an APK, Zip or anything.<br>
Then, you take the copyrighted material (a PNG for example)<br>
You feed it inside bitripper, and this happens:<br>
  Bitripper maps out all the bits inside the copyrighted file<br>
  Then, it maps all the bits that match inside the file you want to "extract" it from.<br>
  It creates a map of the bits, and boom, you have made a legal extractor.<br><br>

For example, take 1st bit from APK, take 5th bit from APK etc until it has gotten your copyrighted material.<br><br>

This gives you 2 advantages: 
1. It is an escape hatch from DMCA
2. The software doesn't know what the copyrighted material is, it just uses the APK file as a "key".
